TRENER ALFIKA – PWA

1. Wgraj WSZYSTKIE pliki i foldery z tego ZIP-a do głównego katalogu repozytorium GitHub.
2. GitHub: Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /(root), Save.
5. Otwórz podany adres strony na Androidzie w Chrome.
6. Kliknij niebieski przycisk „Zainstaluj Trener Alfika na telefonie”, jeśli się pojawi.
7. Alternatywnie Chrome > menu ⋮ > Zainstaluj aplikację / Dodaj do ekranu głównego.

Po pierwszym pełnym załadowaniu aplikacja zapisuje pliki do pracy offline.
