TRENER ALFIKA – MICHAŁ 3.0

1. Otwórz plik index.html w Chrome lub Edge.
2. Folder assets musi pozostać obok pliku index.html.
3. Aplikacja działa lokalnie, bez internetu.
4. Postępy są zapisywane w localStorage przeglądarki na tym komputerze.

Nowe funkcje:
- sesje 10/20 zadań,
- konkursowa punktacja: +3/+4/+5, błędna odpowiedź = -1/4 wartości,
- statystyki według kategorii,
- lista zadań do powtórki,
- trening adaptacyjny,
- automatyczne zwiększanie trudności 3 -> 4 -> 5 pkt.
